## 1. Стек используемых технологий

### Среда исполнения и архитектурный каркас
- **Язык**: TypeScript 5.6 (строгий режим `strict: true`, строгая типизация domain-сущностей, DTO и API).
- **Платформа**: Node.js 20+ / 22+ LTS.
- **Фреймворк**: Next.js 14 (App Router):
  - Серверные Route Handlers (`/api/games`, `/api/games/[id]`, `/api/crawler/trigger`, `/api/crawler/status`, `/api/crawler/stream`, `/api/cron`).
  - Server-Sent Events (SSE) для трансляции логов краулера в реальном времени.
  - Клиентский SPA-дашборд на React 18 с оптимизированным рендерингом и модальными окнами детальной аналитики.
- **Архитектурный паттерн**: Clean Architecture:
  - `domain`: чистые бизнес-сущности (`Game`, `PlatformScore`, `ReviewSummary`, `LetsPlayAnalysis`, `WorkerStatus`, `CrawlLog`) и контракты (`IGameRepository`, `ICrawlStateRepository`).
  - `application`: юзкейсы (`CrawlMetacriticUseCase`, `GetGamesUseCase`, `FindSimilarGamesUseCase`).
  - `infrastructure`: внешние сервисы и адаптеры (парсер `MetacriticCrawler`, модуль ИИ `AISummarizerService`, видеосервис `YouTubeService`, движок схожести `GameSimilarityEngine`, репозиторий `SqliteOrJsonGameRepository`).
  - `presentation`: UI-компоненты и API роуты.

### UI и стилизация
- **Tailwind CSS**: строгая нейтральная палитра Slate / Zinc, стилистика Linear / GitHub Dark без неоновых градиентов и визуального шума.
- **Lucide React**: легковесные контурные иконки.

### Хранилище данных
- **SqliteOrJsonGameRepository**: гибридный репозиторий с автоматическим переключением между файловым snapshot-хранилищем (`data/games.json` / `/tmp/games.json` для serverless окружений типа Vercel) и SQLite. Позволяет мгновенно разворачивать проект без внешних тяжелых БД.

### Тестирование и контейнеризация
- **Jest 29 + ts-jest**: 17 модульных и интеграционных тестов с моками внешних сетевых вызовов.
- **Docker + Docker Compose**: мультистейдж сборка (Alpine/Node) для изолированного продакшн-запуска.

## 2. Как парсились данные (Scraping & Data Ingestion Pipeline)

Парсинг Metacritic реализован в модуле `MetacriticCrawler.ts` с использованием библиотеки **Cheerio** и нативного `fetch` с `AbortSignal.timeout`:

### Логика обхода (Crawl Strategy)
1. **Первый запуск за календарный день**:
   - Краулер обращается к `https://www.metacritic.com/game/` (раздел New Releases).
   - Извлекает первые 20 релизов дня.
2. **Последующие ежечасные запуски в течение дня**:
   - Краулер инкрементально опрашивает страницы каталога `https://www.metacritic.com/browse/game/all/all-time/new/?page=N`.
   - Номер страницы инкрементируется при каждом прогоне и сохраняется в репозитории состояния `CrawlStateRepository`.
3. **Сброс по наступлению новых суток**:
   - При смене календарной даты смещение страниц сбрасывается на 1, реестр обработанных за день игр очищается, и цикл начинается заново с раздела New Releases.
4. **Дедупликация**:
   - Ведется учет обработанных за текущие сутки slug'ов (`processedTodaySlugs`). Если игра уже обрабатывалась сегодня, она не создается повторно, а ее скоры и аналитика обновляются.

### Извлечение данных
- Из карточек и детальных страниц извлекаются:
  - Название игры, slug, канонический URL.
  - Обложка (cover image).
  - Платформы и соответствующие им Metascore и User Score (PC, PS5, Xbox Series X, Nintendo Switch).
  - Студия-разработчик и издатель.
  - Текстовое описание и жанры.
  - Ссылки на официальные видео/трейлеры.
  - Отдельные пулы отзывов: профессиональные рецензии критиков и отзывы игроков.

### Защита от блокировок и зеркальный Fallback
- Metacritic использует защиту Cloudflare и SPA-гидрацию Nuxt.
- В запросах эмулируются реалистичные десктопные заголовки (`User-Agent`, `Accept-Language: en-US`).
- В случае блокировки (капча Cloudflare, 403 Forbidden, сетевой таймаут) краулер автоматически переключается на встроенный зеркальный датасет (`SEED_GAMES`). Это гарантирует 100% отказоустойчивость сервиса и тестов при любых внешних сбоях.

## 3. Где брались ключи для ИИ или использовались заглушки

Генерация и саммаризация аналитики реализована в `AISummarizerService.ts` и `YouTubeService.ts`.

### Источники ключей для LLM
1. **Google Gemini API**:
   - Модель: `gemini-1.5-flash`.
   - Где брать: бесплатный ключ получается в консоли [Google AI Studio](https://aistudio.google.com) (поддерживает до 15 запросов в минуту бесплатно).
   - Переменная окружения: `GEMINI_API_KEY`.
2. **Groq API**:
   - Модель: `llama-3.1-8b-instant`.
   - Где брать: бесплатный ключ регистрируется в [Groq Console](https://console.groq.com) (сверхбыстрый LPU-инференс).
   - Переменная окружения: `GROQ_API_KEY`.
3. **OpenRouter API**:
   - Переменная окружения: `OPENROUTER_API_KEY`.

### Каскадная отказоустойчивость (Fallback Architecture)
Для обеспечения бесперебойной работы без обязательного наличия платных API-ключей и для предотвращения сбоев при исчерпании лимитов (Rate Limit 429) выстроена трехуровневая цепочка:

1. **Уровень 1**: Если задан `GEMINI_API_KEY`, выполняется прямой запрос к Gemini 1.5 Flash с принудительным JSON-режимом (`responseMimeType: application/json`).
2. **Уровень 2**: При ошибке Gemini или его отсутствии опрашивается Groq Llama-3.1 через OpenAI-совместимый интерфейс с флагом `response_format: { type: "json_object" }`.
3. **Уровень 3 (Эвристический детерминированный NLP-движок)**:
   - Если API-ключи не заданы, отсутствует интернет или внешние API вернули ошибку, управление передается методу `fallbackHeuristicSummary()`.
   - Движок выполняет контентный анализ реальных отзывов:
     - Анализ тональности по позитивным и негативным маркерам (`great`, `masterpiece`, `smooth`, `bug`, `lag`, `clunky` и др.).
     - Извлечение сильных и слабых сторон игры на основе оценок и текста.
     - Формирование структурированного консенсуса критиков и игроков.
   - Формат ответа эвристики на 100% совпадает со схемой ответа нейросетей (`liked`, `disliked`, `consensus`).

## 4. YouTube Let's Play & Gameplay Analysis

Модуль `YouTubeService.ts`:
1. Формирует поисковый запрос к YouTube с фильтром по просмотрам (`sp=CAM%253D`).
2. Извлекает метаданные из блока `ytInitialData` (название видео, имя стримера/канала, число просмотров, videoId).
3. Извлекает транскрипт геймплейного ролика.
4. Отправляет транскрипт в LLM (Gemini / Groq) для выделения:
   - Краткого саммари прохождения.
   - Плюсов и минусов, замеченных стримером в реальном времени.
   - Финального вердикта стримера ("Blogger Verdict").
5. При недоступности YouTube парсинга используется детерминированный фолбэк на проверенные каналы (IGN, theRadBrad) без сбоев пайплайна.

## 5. Алгоритм поиска похожих игр (GameSimilarityEngine)

Алгоритм вычисляет коэффициент схожести по взвешенной формуле:
- **Жанры (Jaccard Index)**: вес 45% (пересечение жанров деленное на их объединение).
- **Студия-разработчик**: вес 25% (точное совпадение студии).
- **Платформы**: вес 15% (доля общих поддерживаемых платформ).
- **Близость Metascore**: вес 15% (нормализованная дельта оценок).
